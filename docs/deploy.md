# Развёртывание на VPS

Чтобы бот работал круглосуточно, его удобно держать на недорогом VPS.
На сервере он работает в Docker: сам перезапускается при сбое и после перезагрузки сервера.

## Шаг 1. Арендовать сервер

> ⚠️ **Важно: бери сервер в зарубежной локации** (Нидерланды, Финляндия, Германия, Казахстан и т.п.).
> С весны 2026 года российские хостинги массово не пропускают запросы к API Telegram — бот на таком
> сервере просто не получит ни одного сообщения. Агрегатор Polza при этом работает откуда угодно.

Нужен провайдер, который принимает российские карты и даёт зарубежные локации — например, Aeza или
Timeweb Cloud (сравни цены на сайтах, они часто меняются). Параметры:
- **ОС:** Ubuntu 24.04;
- **память:** 1 ГБ (боту хватает с запасом), процессор — 1 ядро, диск — от 10 ГБ;
- лучше с почасовой оплатой: если с сервера что-то не заработает, его можно удалить, почти ничего не потеряв.

После оплаты в панели хостинга (или в письме) будут **IP-адрес** сервера (вида `185.12.34.56`)
и **пароль от root** — это главный пользователь сервера. Ниже вместо `1.2.3.4` подставляй свой IP.

## Шаг 2. Подключиться к серверу

С Windows — в PowerShell (программа `ssh` уже встроена):
```powershell
ssh root@1.2.3.4
```
- первый раз спросит `Are you sure you want to continue connecting` — напиши `yes` и Enter;
- потом пароль: при вводе символы **не отображаются**, это нормально. Вставить из буфера — правой кнопкой мыши;
- появится строка вида `root@server:~#` — ты на сервере. Выйти — команда `exit`.

С телефона — приложение **Termius** (Android/iOS): «New host» → IP, пользователь `root`, пароль.

**Чтобы не вводить пароль каждый раз** (скрипт выкладки подключается несколько раз), сделай SSH-ключ — один раз, на ПК:
```powershell
ssh-keygen -t ed25519
```
(на все вопросы — просто Enter), затем отправь ключ на сервер (последний раз попросит пароль):
```powershell
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh root@1.2.3.4 "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

## Шаг 3. Подготовить сервер (один раз)

На ПК, в PowerShell из папки проекта:
```powershell
powershell -ExecutionPolicy Bypass -File tools\deploy.ps1 -Server root@1.2.3.4 -Setup
```
Скрипт установит на сервер Docker и выставит часовой пояс. Займёт пару минут.

## Шаг 4. Переехать

1. **Останови бота на ПК** (Ctrl+C в его окне). Два запущенных бота мешают друг другу.
2. Выложи бота на сервер вместе с базой (вся память Ники, история, отношения, картинки):
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\deploy.ps1 -Server root@1.2.3.4 -WithData
   ```
   Скрипт упакует проект и `.env`, отправит на сервер, соберёт и запустит. Первая сборка — 2–5 минут.
3. Проверь, что с сервера доступны Telegram и Polza:
   ```powershell
   ssh root@1.2.3.4 "cd ~/nika && docker compose run --rm nika python -m tools.check_connectivity"
   ```
   Должно быть две зелёные галочки. Если Telegram ❌ — см. «Если Telegram недоступен» ниже.
4. Напиши Нике в Telegram — она должна ответить и помнить всё, что было.

## Проверка

1. Выключи ПК (или просто закрой все окна) — Ника продолжает отвечать.
2. Перезагрузи сервер и через 1–2 минуты напиши Нике — она должна ответить:
   ```powershell
   ssh root@1.2.3.4 reboot
   ```

## Повседневное

**Логи** (что делает бот, ошибки). Выход из просмотра — Ctrl+C:
```powershell
ssh root@1.2.3.4 "cd ~/nika && docker compose logs --tail 100 -f"
```

**Обновление** — после изменений в коде, `persona.yaml` или `.env`:
```powershell
powershell -ExecutionPolicy Bypass -File tools\deploy.ps1 -Server root@1.2.3.4
```
> ⚠️ Без `-WithData`! Этот ключ заменяет базу на сервере базой с ПК, а на сервере память свежее.
> (Старая база на всякий случай сохраняется как `data/nika.db.before-upload`.)

**Остановить / запустить / перезапустить** бота на сервере:
```powershell
ssh root@1.2.3.4 "cd ~/nika && docker compose down"
ssh root@1.2.3.4 "cd ~/nika && docker compose up -d"
ssh root@1.2.3.4 "cd ~/nika && docker compose restart"
```

**Скачать бэкапы на ПК** (на сервере хранятся 7 последних дней):
```powershell
scp -r root@1.2.3.4:~/nika/data/backups .\server_backups
```

## Восстановление из бэкапа

Если база испортилась или хочется откатиться на день назад:
```powershell
ssh root@1.2.3.4
```
и уже на сервере:
```bash
cd ~/nika
docker compose down
ls data/backups
cp data/nika.db data/nika.db.broken
cp data/backups/nika-2026-10-25.db data/nika.db
docker compose up -d
```
(во 2-й строке смотришь список копий, в 5-й подставляешь нужную дату).

## Если Telegram недоступен с сервера

Проще всего — взять сервер в другой стране. Если хочется остаться на этом, в `.env` можно указать
прокси (`TELEGRAM_PROXY=socks5://логин:пароль@адрес:порт`) или свой релей Bot API за рубежом
(`TELEGRAM_API_URL=https://...`), затем выложить обновление через `deploy.ps1`.
