# Установка и запуск на своём компьютере

Нужен Python 3.12+ и аккаунт у агрегатора нейросетей с OpenAI-совместимым API
(я пользуюсь [Polza.ai](https://polza.ai) — принимает российские карты, минимальное пополнение 100 ₽).

## 1. Бот в Telegram

1. Написать [@BotFather](https://t.me/BotFather) → `/newbot` → придумать имя и username (должен заканчиваться на `bot`).
2. Сохранить токен вида `1234567890:AAH...` — это пароль от бота, никому не показывать.
   Если засветился — `/revoke` у BotFather выдаст новый.
3. Узнать свой числовой ID у [@userinfobot](https://t.me/userinfobot) — бот будет отвечать только этому ID.

## 2. Ключ агрегатора

В личном кабинете Polza: пополнить баланс → «API-ключи» → создать ключ.
При создании я ставлю лимит расходов на месяц и выключаю логирование запросов и неофициальных провайдеров.

## 3. Установка

```powershell
git clone https://github.com/liceriusminar-lab/nika-bot.git
cd nika-bot
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

В `.env` обязательно заполнить `TELEGRAM_BOT_TOKEN`, `OWNER_TELEGRAM_ID`, `CHAT_BASE_URL`, `CHAT_API_KEY`
и `CHAT_MODEL`. Остальное — по желанию, у всего есть разумные значения по умолчанию,
каждое поле подписано прямо в `.env.example`. Файл сохранять в UTF-8.

На Linux/macOS всё то же самое, только `python3 -m venv .venv`, `.venv/bin/python` и `cp` вместо `Copy-Item`.

## 4. Выбор модели

Разные модели по-разному держат образ и пишут по-русски, поэтому перед первым запуском стоит прогнать сравнение:

```powershell
.\.venv\Scripts\python.exe -m tools.compare_models
```

Скрипт отправит 12 тестовых реплик (болтовня, флирт, грусть, начало и продолжение RP, выход из роли и т.д.)
в несколько моделей и сохранит ответы в HTML-таблицу в `tools/` вместе с прикидкой цены в месяц.
Свой набор моделей: `--models deepseek/deepseek-v4-flash,qwen/qwen3-32b`. Прогон стоит пару рублей.

Что выбрал я: `deepseek/deepseek-v4-pro-0813` для разговора и `deepseek/deepseek-v4-flash` для служебных задач —
выходит порядка 100 ₽ в месяц при ~50 сообщениях в день.

## 5. Запуск

```powershell
.\.venv\Scripts\python.exe -m bot.main
```

В консоли появится `Бот @... запущен`. Остановить — Ctrl+C. Логи также пишутся в `data/logs/bot.log`.

Проверить, что с машины доступны Telegram и агрегатор:

```powershell
.\.venv\Scripts\python.exe -m tools.check_connectivity
```

## 6. Тесты

```powershell
.\.venv\Scripts\python.exe -m pytest
```

Нейросети в тестах подменены, так что они бесплатные и работают без интернета.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| `Ошибка в настройках (.env): проверь поля ...` | `.env` не создан или поле пустое |
| `Telegram не принял токен` | токен скопирован не полностью — взять заново у @BotFather |
| `Нет связи с серверами Telegram` | интернет или блокировка — см. `TELEGRAM_PROXY` в `.env.example` |
| Бот молчит | проверить `OWNER_TELEGRAM_ID` — там должен быть именно твой ID |

## Тестовый режим «пишет первой»

Чтобы не ждать часами, в `.env` можно поставить `PROACTIVE_TEST_MODE=true`: проверка идёт каждую минуту,
«давно молчит» — это 2–4 минуты, между её сообщениями — 3 минуты, «пропал» — 10 минут.
Утро, вечер и «поделиться» в этом режиме отключены. После проверки вернуть `false`.
