# Запуск на старом Android-телефоне

Вместо VPS бота можно держать на ненужном телефоне: он постоянно лежит на зарядке, подключён к домашнему Wi-Fi,
а бот работает в Termux внутри Ubuntu (proot-distro). Бесплатно и круглосуточно.
Подойдёт почти любой телефон с Android 7+ и 64-битным процессором, свободного места нужно около 2 ГБ.

## 1. Termux и Termux:Boot

Ставить оба приложения из одного источника — [F-Droid](https://f-droid.org/packages/com.termux/)
или [релизов на GitHub](https://github.com/termux/termux-app/releases) (версия из Google Play устарела).
[Termux:Boot](https://f-droid.org/packages/com.termux.boot/) нужен для автозапуска после перезагрузки —
после установки его надо один раз открыть.

В настройках Android для Termux: батарея — «Без ограничений», и включить автозапуск, если есть такой пункт
(на realme, Xiaomi, Huawei без этого система убивает фоновые приложения).

## 2. Перенести настройки и базу

С компьютера скопировать в папку **Download** телефона (кабелем, режим «Передача файлов»):
- `.env` → переименовать в **`nika.env`** (Android прячет файлы, начинающиеся с точки);
- `data/nika.db` → **`nika.db`** — если хочется перенести память с компьютера. Бот на компьютере перед этим остановить.

После установки скрипт перенесёт оба файла к боту и удалит их из «Загрузок».

## 3. Установка

В Termux одной строкой:

```bash
curl -fsSL https://raw.githubusercontent.com/liceriusminar-lab/nika-bot/main/tools/android/setup.sh | bash
```

Во время установки Android попросит доступ к файлам — разрешить. Первая установка занимает 10–20 минут
(скачивается Ubuntu и библиотеки Python). В конце скрипт проверит связь с Telegram и агрегатором и запустит бота.

## Управление

| Команда в Termux | Что делает |
|---|---|
| `~/nika-log.sh` | лог бота (выход — Ctrl+C) |
| `~/nika-stop.sh` | остановить |
| `~/nika-start.sh` | запустить |
| `~/nika-update.sh` | обновить из GitHub и перезапустить |

Termux можно свернуть, но не смахивать из списка недавних приложений.
Если бот упадёт, `nika-run.sh` перезапустит его через 10 секунд, а после перезагрузки телефона его поднимет Termux:Boot.
Ежедневные бэкапы базы лежат там же, где и на сервере, — в `data/backups/` внутри Ubuntu
(`$PREFIX/var/lib/proot-distro/installed-rootfs/ubuntu/root/nika/data/backups`).
